# Carry

A tiny local-first todo PWA for iPhone. It installs from Safari with **Add to Home Screen**, stores data locally on the device, works offline, and automatically carries unfinished tasks into the next day.

## Run Locally

```sh
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Install on iPhone

1. Publish this folder with GitHub Pages.
2. Open the GitHub Pages URL in Safari on the iPhone.
3. Tap Share, then **Add to Home Screen**.

The app will keep working offline after the first load.
